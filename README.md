## 🎯 How to Add This Source

To install these applications on your iOS device, you need to add this repository to your [AltStore](https://altstore.io/).

### Method 1: Direct Link (Mobile)
If you are viewing this on your iPhone with AltStore installed, simply tap the button below:

<a href="altstore://source?url=https://matthieuduga.github.io/ios-apps/repo.json">
  <img src="https://img.shields.io/badge/Add_to_AltStore-43C3CE?style=for-the-badge&logo=apple" alt="Add to AltStore" />
</a>

### Method 2: Manual Add
1. Open **AltStore** on your iOS device.
2. Navigate to the **Sources** tab.
3. Tap the **+** icon in the top right corner.
4. Paste the following URL:
   ```text
   https://matthieuduga.github.io/ios-apps/repo.json
   ```
